# Glosario
| Término | Significado |
|---|---|
| CRM Core | Dominio y operación comercial central |
| Tenant / Organization | Organización aislada en CRM |
| ManyChat | Módulo conversacional WHATSPOWER |
| Watson | Módulo campañas/difusión WHATSPOWER-ULTRA |
| Agente principal | Agente único que, según propietario, pertenece a CRM; implementación requiere reconciliar HARNESS |
| Daemon | Servicio WhatsApp operado por CRM |
| HMAC | Firma criptográfica de webhook |
| JIT lock | Comprobación justo antes del despacho |
| Suppression / Opt-out | Regla que impide contactar a quien solicitó baja |
| Handoff | Transferencia a humano |
| Bridge | Adaptador de comunicación entre repos |
| MemoryDV | Contrato de memoria descrito en HARNESS |
| MCP | Model Context Protocol |
| ChannelConnection | Modelo multi-cuenta propuesto, no confirmado |
| Fail-closed | Ante imposibilidad de validar, denegar |
| Idempotencia | Repetición sin duplicar efectos |
| VERIFIED | Comprobado directamente con evidencia |
| REPORTED | Afirmado por informe, no reproducido en el corte |
